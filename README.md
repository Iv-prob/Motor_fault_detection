# Проекты по предиктивной аналитике и автоматизации (Python / ML / SQL)

Репозиторий содержит мои практические проекты в рамках подготовки к стажировке в бигтех-компаниях.

## 1. Проект: Прогнозирование параметров промышленного оборудования (Machine Learning)
* **Задача:** Регрессионный анализ физических параметров станка (прогнозирование крутящего момента).
* **Стек:** `Python`, `Scikit-Learn`, `Pandas`, `NumPy`.
* **Датасет:** AI4I 2020 Predictive Maintenance Dataset (10 000 строк промышленной телеметрии).
* **Результаты:** Обучена модель `RandomForestRegressor`. За счет подбора гиперпараметров глубин деревьев удалось победить переобучение и достичь метрик: **R2 = 0.84**, **MAE = 2.95 Нм**.

## 2. Проект: Автоматизация аналитики (Python + SQL)
* **Задача:** Перенос зашумленных CSV-логов в реляционную базу данных и расчет агрегированных показателей.
* **Стек:** `Python`, `sqlite3`, `Pandas`.
* **Результаты:** Реализованы SQL-запросы высокой сложности с использованием операторов `GROUP BY`, `JOIN`, `AVG` и `WHERE` для мгновенного выявления скрытых маркеров аварийных состояний оборудования.
